요청하신 내용을 기준으로 보면, “매집비(매집 등급)”는 **실제 수학적·통계적으로 복잡한 AI라기보다는, 증권사 창구별 수급 데이터를 정규화하여 만든 지표형 스코어링 모델**에 가깝습니다.
아래에서는 **공식화가 가능한 형태로 정리**해 드리겠습니다. 이대로 구현하면 “매집비 유사 프로그램”을 만들 수 있습니다.

---

## 1. 매집비의 구조 요약 (핵심)

매집비 등급은 **알파벳 3글자**이며, 각각 **서로 다른 수급 관점의 비율 지표**입니다.

| 알파벳  | 의미                | 핵심 비교 기준                |
| ------- | ------------------- | ----------------------------- |
| 첫 번째 | 큰손 매수/매도 비율 | 매수량 ÷ 매도량               |
| 두 번째 | 다수 창구 매집 비율 | 총 매집량 ÷ 유통주식수        |
| 세 번째 | 단일 창구 집중 매집 | 특정 창구 매집량 ÷ 유통주식수 |

즉, **전부 “비율 계산”**입니다.

---

## 2. 첫 번째 알파벳 공식 (매집비의 핵심)

### 정의

> **큰손 매수 대비 큰손 매도 비율**

### 공식

```text
첫번째 매집비(%) = (큰손 매수량 ÷ 큰손 매도량) × 100
```

### 예시

* 큰손 매수량: 3,480,000주
* 큰손 매도량: 1,000,000주

```text
(3,480,000 ÷ 1,000,000) × 100 = 348%
```

➡ **A 등급 (300% 이상)**

### 등급 기준

| 등급 | 비율      |
| ---- | --------- |
| A    | 300% 이상 |
| B    | 200~299%  |
| C    | 130~199%  |
| D    | 129% 이하 |

📌 **포인트**

* “큰손”은 보통 **상위 N개 증권사 창구(거래량 기준)**로 정의
* 개인은 제외하거나, 프로그램상 **거래 상위 5~10개 창구**로 대체 가능

---

## 3. 두 번째 알파벳 공식 (다수 세력 매집)

### 정의

> **여러 증권사를 통한 누적 매집량이 유통주식수에서 차지하는 비율**

### 공식

```text
두번째 매집비(%) = (다수 창구 순매수 합계 ÷ 유통주식수) × 100
```

### 예시

* 다수 창구 순매수 합계: 4,200,000주
* 유통주식수: 70,000,000주

```text
(4,200,000 ÷ 70,000,000) × 100 = 6.0%
```

➡ **A 등급 (5% 이상)**

### 등급 기준

| 등급 | 비율       |
| ---- | ---------- |
| A    | 5% 이상    |
| B    | 3.0~4.9%   |
| C    | 1.5~2.9%   |
| D    | 1.49% 이하 |

📌 **포인트**

* “다수”란 **2개 이상 창구**
* 동일 날짜·기간 합산

---

## 4. 세 번째 알파벳 공식 (단일 창구 집중 매집)

### 정의

> **특정 증권사(단일 창구)가 매집한 물량 비중**

### 공식

```text
세번째 매집비(%) = (최대 순매수 창구 물량 ÷ 유통주식수) × 100
```

### 예시

* 특정 창구 순매수: 3,800,000주
* 유통주식수: 70,000,000주

```text
(3,800,000 ÷ 70,000,000) × 100 = 5.43%
```

➡ **A 등급**

### 등급 기준

| 등급 | 비율       |
| ---- | ---------- |
| A    | 5% 이상    |
| B    | 3.0~4.9%   |
| C    | 1.5~2.9%   |
| D    | 1.49% 이하 |

📌 **포인트**

* “주포 가능성” 판단 지표
* 단일 창구 쏠림이 핵심

---

## 5. AAA가 의미하는 상태 (정리)

AAA란 다음 조건을 **동시에 만족**한 상태입니다.

1. **큰손 매수량 ≥ 큰손 매도량의 3배**
2. **다수 창구 누적 매집 ≥ 유통주식수의 5%**
3. **특정 단일 창구 매집 ≥ 유통주식수의 5%**

즉,

> **세력의 물량 확보가 이미 끝났고,
> 매도 압력보다 매수 압력이 구조적으로 우위**

라는 뜻입니다.

## 6. 프로그램 구현용 최소 로직 (의사 코드)

```pseudo
for 종목 in 시장:
    기간 = 사용자 지정 기간

    큰손_매수 = 상위창구 매수 합계
    큰손_매도 = 상위창구 매도 합계

    비율1 = (큰손_매수 / 큰손_매도) * 100
    등급1 = 등급판정(비율1)

    다수창구_순매수 = 2개 이상 창구 순매수 합
    비율2 = (다수창구_순매수 / 유통주식수) * 100
    등급2 = 등급판정(비율2)

    최대창구_순매수 = 창구별 순매수 중 최대값
    비율3 = (최대창구_순매수 / 유통주식수) * 100
    등급3 = 등급판정(비율3)

    출력 = 등급1 + 등급2 + 등급3
```

## 7. 중요한 현실적 한계 (반드시 인지해야 함)

* **증권사 창구 = 실제 세력 1명 아님**
* 분할 계좌, 차명, 프로그램 매매로 왜곡 가능
* “매집 완료 = 즉시 상승”은 아님 (시간 지연 존재)

➡ **매집비는 “진입 필터”이지, 매수 버튼이 아님**
